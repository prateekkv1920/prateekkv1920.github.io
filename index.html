ACT II • 2024 – 2025

The Agentic Architect: Code That Reasons & Validates

Multi-Agent Systems & Deterministic Containment

In early 2024, everyone was building generic chat wrappers. But if you've ever hooked an LLM directly to a production SQL database, you know the terror: hallucinations, dropped tables, syntax errors, and zero safety guarantees.

I decided to solve this head-on. I architected SQL-GPT-Omni — not as a single prompt, but as a deterministic tri-agent containment pipeline. Step 1 interprets natural language. Step 2 parses and writes dialect-specific SQL. Step 3 intercepts the query through an Abstract Syntax Tree (AST) validator to verify read-only constraints. Step 4 generates plain-English execution explanations. The result was a 92% drop in syntax errors and zero destructive queries.

Next came Promptly Evaluate v2. When working with enterprise AI, you cannot evaluate models on "vibes". I built an automated multi-provider benchmarking harness that quantitatively evaluates prompt outputs for latency, token economics, and hallucination containment.
