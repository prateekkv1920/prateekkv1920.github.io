ACT II • 2024 – 2025

The Agentic Architect: Code That Reasons & Validates

Multi-Agent Systems & Deterministic Containment

In 2024, the tech world was flooded with brittle single-shot LLM prompts. But if you've ever hooked an LLM directly to a relational database, you know the hazard: hallucinated columns, syntax breakdowns, and unsafe execution.

I engineered SQL-GPT — not as a simple prompt, but as a modular, asynchronous multi-agent system built on LangChain and LangGraph. The architecture decouples responsibility across three specialized agents: a SQL Scripter (content generator), a SQL Validator (schema checking and compilation), and a Query Explainer (content refiner). With a dedicated feedback loop, syntax errors plummeted by 92% while enforcing strict read-only containment guarantees.

To solve the problem of empirical model comparison, I built Promptly Evaluate. Instead of judging LLMs by intuition, it uses a golden dataset of ground-truth profiles, computes cosine semantic similarity using sentence-transformers vector embeddings, and leverages an LLM-as-a-judge approach for rigorous quantitative benchmarking.
